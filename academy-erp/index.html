Calculation rules (as you requested)

  • Hours per Session: entered once when you create the course. Cannot change per session (keeps history clean).
  • 1 session per week: sessions auto-generate every 7 days from the course start date.
  • Total hours every month: sessionsInMonth × hoursPerSession. Shown on Dashboard + per course.
  • Subscription: every student pays every 4 sessions. Start date = you enter. End date = date of 4th session. Example: start Mon 1 Sep → sessions 1,8,15,22 Sep → end = 22 Sep. Next cycle starts 29 Sep.
  • Absence rule: each student has the right to ONE excused absence per whole course. That session is NOT counted → subscription extends +1 week (end = 5th session date). Any further absence is counted as used/paid → no extension.
  • Age: auto-calculated from date of birth.
  • Status per student: Present / Absent-excused / Absent-counted + Paid / Unpaid + subscription start/end + days left.
